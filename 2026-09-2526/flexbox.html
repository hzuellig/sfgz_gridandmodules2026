Flexbox – Elemente an der Leine

Den Document Flow kennt ihr: Elemente ordnen sich einfach untereinander bzw. in der Schreibrichtung an. Heute lernt ihr, wie man Elemente gezielt in einer Reihe oder Spalte anordnet und wie sie mit dem vorhandenen Platz umgehen.

Teil 1: Vom Document Flow zu Flexbox

Der Document Flow ist die Anordnung der Seitenelemente, wie sie durch die Reihenfolge im HTML und die Positionierungsanweisungen definiert ist – also wie die Elemente Platz einnehmen und sich umeinander anordnen. Ohne CSS-Anweisungen orientiert sich der Document Flow an der Schreibrichtung (westeuropäisch: von links nach rechts und von oben nach unten).

Aber: Wie entsteht ein Layout mit mehreren Spalten? Oder eine Navigation, bei der die Links nebeneinander stehen und den Platz gleichmässig aufteilen?

Lange war das nur mit Umwegen möglich. In den 1990ern baute man Layouts mit Tabellen, später mit float – einer Eigenschaft, die eigentlich dafür gedacht war, ein Bild von Text umfliessen zu lassen. Beides waren Hacks. Erst mit Flexbox (breit unterstützt seit etwa 2015) und Grid (seit 2017) bekam CSS echte Layout-Werkzeuge.

Flexbox Grid
ordnet Elemente in eine Richtung an: in einer Zeile oder einer Spalte ordnet Elemente in zwei Richtungen an: in Zeilen und Spalten
denkt vom Inhalt aus: Wie viel Platz braucht jedes Element? denkt von der Fläche aus: Wie ist der Raum aufgeteilt?
Stellt euch eine Flexbox wie eine Wäscheleine vor. Die Leine gibt die Richtung vor, in der alles aufgereiht wird. Ihr entscheidet, ob die Wäsche dicht gedrängt am Anfang hängt, gleichmässig verteilt ist oder in der Mitte zusammenrückt. Und die Schwerkraft zieht quer dazu – die Stücke hängen nach unten, unterschiedlich lang.

Diese Leine seht ihr in allen Beispielen unten. Jede Leine ist ein echter Flex-Container – ihr könnt im Browser mit den DevTools reinschauen.

Teil 2: Container und Kinder

Flexbox funktioniert immer mit zwei Ebenen: Die Eigenschaft display: flex wird beim Parent-Element gesetzt (dem Container, der Leine). Die Flexbox-Anweisungen bestimmen dann, wie sich die Kinder (die Wäschestücke) darin anordnen.

<div class="leine">
  <div class="stueck">1</div>
  <div class="stueck">2</div>
  <div class="stueck">3</div>
  <div class="stueck">4</div>
</div>
.leine {
  display: flex;   /* macht aus dem Parent einen Flex-Container */
}
.stueck {
  border: 1px dotted blue;
  padding: 1rem;
}

Sobald display: flex gesetzt ist, stehen die Kinder nebeneinander statt untereinander – auch wenn es eigentlich Block-Elemente wie <div> sind.

Merke: Flexbox wirkt immer nur auf die direkten Kinder. Die Enkel-Elemente sind davon nicht betroffen – ausser, ihr macht das Kind selbst wieder zum Flex-Container (siehe Teil 8).

Teil 3: Hauptachse und Querachse

Jede Flexbox hat zwei Achsen:

  • Hauptachse – die Leine. In dieser Richtung werden die Elemente aufgereiht.
  • Querachse – die Schwerkraft. Sie steht immer rechtwinklig zur Hauptachse.

Mit flex-direction legt ihr fest, in welche Richtung die Hauptachse läuft:

Wert Hauptachse Querachse
row (Standard) links → rechts oben → unten
row-reverse rechts → links oben → unten
column oben → unten links → rechts
column-reverse unten → oben links → rechts 
.leine {
  display: flex;
  flex-direction: column;   /* Elemente untereinander */
}
Wichtig: justify-content wirkt immer entlang der Hauptachse, align-items immer entlang der Querachse. Das ist nicht dasselbe wie „horizontal“ und „vertikal“! Sobald ihr flex-direction: column setzt, tauschen die beiden ihre Richtung. Das ist der häufigste Stolperstein bei Flexbox.

Die Richtung hängt übrigens von der Schreibrichtung ab: Auf einer arabischen oder hebräischen Seite (von rechts nach links) läuft row automatisch von rechts nach links. Deshalb spricht CSS von start und end statt von links und rechts.

Zentrieren – horizontal und vertikal

Kombiniert ihr beide Eigenschaften, könnt ihr ein Element in beide Richtungen zentrieren – lange eine der schwierigsten Aufgaben in CSS, mit Flexbox sind es drei Zeilen:

.container {
  display: flex;
  justify-content: center;   /* Hauptachse */
  align-items: center;       /* Querachse */
  height: 100vh;             /* ohne Höhe gibt es nichts zu zentrieren */
}

Teil 6: gap – Abstand zwischen den Klammern

Mit gap legt ihr den Abstand zwischen den Elementen fest. Das ist viel einfacher als mit margin bei den Kindern: Der Abstand entsteht nur zwischen den Elementen, nicht am Rand.

.leine {
  display: flex;
  gap: 1rem;            /* gleicher Abstand in beide Richtungen */
  /* row-gap: 2rem;       nur zwischen Zeilen   */
  /* column-gap: 1rem;    nur zwischen Spalten  */

Teil 7: flex-wrap – die zweite Leine

Standardmässig bleiben alle Elemente auf einer einzigen Leine – auch wenn es eng wird. Sie werden dann gestaucht oder ragen über den Rand hinaus. Mit flex-wrap: wrap erlaubt ihr einen Umbruch: Ist die Leine voll, geht es auf der nächsten weiter.

.leine {
  display: flex;
  flex-wrap: wrap;   /* Standard: nowrap */
                     /* auch möglich: wrap-reverse */
}

Teil 8: Wachsen und schrumpfen

Bis jetzt hatten alle Elemente eine feste Breite, und Flexbox hat nur den übrigen Platz verteilt. Jetzt kommt der Teil, der Flexbox den Namen gibt: Die Elemente selbst können sich dehnen oder zusammenziehen. Diese Eigenschaften setzt ihr beim Kind, nicht beim Container.

flex-basis – die Ausgangsgrösse

flex-basis legt fest, wie gross ein Element entlang der Hauptachse sein möchte. Ihr könnt es euch wie width vorstellen (bzw. height bei column). Der Unterschied: Von dieser Basis aus darf das Element wachsen oder schrumpfen.

flex-grow – wachsen, wenn Platz da ist

flex-grow ist ein Wachstumsfaktor. Er bestimmt, wie der freie Platz verteilt wird. Standard ist 0 – das Element wächst nicht.

Denkfalle: flex-grow: 2 heisst nicht, dass das Element doppelt so breit wird. Es bekommt doppelt so viel vom freien Platz, der nach der flex-basis übrig bleibt. Schaut euch das mittlere Beispiel oben genau an.

flex-shrink – schrumpfen, wenn es eng wird

flex-shrink ist das Gegenstück: Wie stark darf ein Element schrumpfen, wenn nicht genug Platz da ist? Standard ist 1 – alle schrumpfen gleichmässig. Mit flex-shrink: 0 behält ein Element seine Grösse, zum Beispiel ein Logo oder ein Icon.

Die Kurzschreibweise flex

In der Praxis schreibt man die drei Werte meistens zusammen, in der Reihenfolge grow, shrink, basis:

.stueck {
  flex: 1 1 200px;   /* grow: 1, shrink: 1, basis: 200px */
}

.stueck {
  flex: 1;           /* Abkürzung: alle teilen sich den Platz gleichmässig */
}

.logo {
  flex: 0 0 120px;   /* fix: wächst nicht, schrumpft nicht, immer 120px */
}

Teil 10: Verschachteln – das Mobile

Ein Kind in einem Flex-Container kann selbst wieder display: flex haben und eigene Kinder anordnen. Und diese wiederum auch – die Tiefe spielt keine Rolle. So entstehen komplexere Layouts aus lauter einfachen Reihen und Spalten.

Denkt an ein Mobile, wie es Alexander Calder oder Bruno Munari gebaut haben: Ein Stab trägt mehrere Elemente, und manche dieser Elemente sind selbst wieder Stäbe mit eigenen Elementen. Jeder Stab ist ein eigener Flex-Container – mit eigener Richtung, eigener Verteilung, eigenem Gleichgewicht.

Drei verschachtelte Ebenen: Stab (row) → Hänger (column) → kleiner Stab (row)

.stab {
  display: flex;                    /* Ebene 1: Elemente nebeneinander */
  justify-content: space-between;
  align-items: flex-start;
}
.haenger {
  display: flex;                    /* Ebene 2: Faden und Kugel untereinander */
  flex-direction: column;
  align-items: center;
}
/* ein .stab kann wieder in einem .haenger hängen – und so weiter */

Typische Beispiele im Web: eine Kopfzeile (row) mit Logo links und einer Navigation rechts, die selbst wieder eine Flexbox mit Links ist. Oder eine Karte (column) mit Bild, Text und einer Button-Reihe (row) unten.

Überblick

Beim Container (Parent):

.container {
  display: flex;

  /* Richtung der Hauptachse */
  flex-direction:  row;          /* Standard */
                   /* row-reverse | column | column-reverse */

  /* Verteilung entlang der Hauptachse */
  justify-content: flex-start;   /* Standard */
                   /* flex-end | center | space-between | space-around | space-evenly */

  /* Ausrichtung entlang der Querachse */
  align-items:     stretch;      /* Standard */
                   /* flex-start | flex-end | center | baseline */

  /* Umbruch */
  flex-wrap:       nowrap;       /* Standard */
                   /* wrap | wrap-reverse */

  /* Abstand zwischen den Kindern */
  gap:             1rem;
}

Bei den Kindern (Items):

.child {
  /* Wachsen, Schrumpfen, Ausgangsgrösse */
  flex-grow:   0;          /* Standard */
  flex-shrink: 1;          /* Standard */
  flex-basis:  auto;       /* Standard */
  flex:        1 1 200px;  /* Kurzschreibweise: grow shrink basis */

  /* align-items für dieses Kind überschreiben */
  align-self:  auto;       /* Standard */
               /* stretch | flex-start | flex-end | center | baseline */

  /* Reihenfolge */
  order:       0;          /* Standard */
}

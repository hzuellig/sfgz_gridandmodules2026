Grid – Bilder an der Wand

Mit Flexbox habt ihr Elemente an einer Leine aufgereiht, in eine Richtung. Mit Grid plant ihr eine ganze Wand: Zeilen und Spalten gleichzeitig, mit Weissraum, Überlagerungen und Bildern, die über mehrere Felder gehen.

Teil 1: Von der Leine zur Wand

Im Unterschied zu Flexbox ist bei Grid das Ausrichten in zwei Richtungen möglich: in Zeilen und Spalten. Damit kommt Grid dem Gestaltungsraster aus der Grafik sehr nahe – dem Raster, das Gestalter wie Josef Müller-Brockmann für Plakate und Bücher entwickelt haben.

Flexbox – die Leine Grid – die Wand
eine Richtung: Zeile oder Spalte zwei Richtungen: Zeilen und Spalten
denkt vom Inhalt aus: Wie viel Platz braucht jedes Element? denkt von der Fläche aus: Wie ist der Raum aufgeteilt?
Elemente reihen sich aneinander Elemente können gezielt platziert werden, mit Lücken und Überlagerungen
Stellt euch eine Ausstellungswand vor, bevor gehängt wird. Mit Bleistift ist ein Raster eingezeichnet: Spalten und Zeilen, nummerierte Linien. Auf dem Hängeplan steht, welches Bild wo hängt – eines über zwei Felder, eines klein in der Ecke, dazwischen bewusst eine leere Fläche. So könnt ihr eine streng geordnete Wand hängen oder eine dichte Petersburger Hängung.

Das Raster ist dabei unsichtbar – es ist ein Hilfsmittel für die Planung, nicht das Bild selbst. Ihr könnt euch damit an Ordnung halten oder es bewusst brechen.

Teil 2: Container und Kinder

Wie bei Flexbox wird die Eigenschaft display: grid beim Parent-Element gesetzt (der Wand). Dazu definiert ihr das Raster: Anzahl und Breite der Spalten, allenfalls auch der Zeilen. Die Kinder (die Bilder) füllen das Raster dann auf.

<div class="wand">
  <div class="bild">1</div>
  <div class="bild">2</div>
  <div class="bild">3</div>
  <div class="bild">4</div>
  <div class="bild">5</div>
  <div class="bild">6</div>
</div>
.wand {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;   /* drei gleich breite Spalten */
  gap: 10px;
}

Ohne weitere Angaben werden die Kinder der Reihe nach eingefüllt: von links nach rechts, und wenn eine Zeile voll ist, in der nächsten. Braucht es mehr Zeilen, als ihr definiert habt, legt der Browser automatisch neue an.

DevTools-Tipp: In Firefox und Chrome erscheint im Inspektor neben jedem Grid-Container ein grid-Badge. Ein Klick darauf blendet das Raster direkt auf der Seite ein – mit den Nummern der Linien. Das ist bei Grid noch hilfreicher als bei Flexbox.

Teil 3: Spalten und Zeilen definieren

Mit grid-template-columns und grid-template-rows legt ihr das Raster fest. Jeder Wert steht für eine Spalte bzw. Zeile. Ihr könnt alle bekannten Einheiten verwenden – und eine neue.

Die Einheit fr

fr steht für fraction, also Anteil. Sie nimmt den verfügbaren Platz nach Abzug aller fixen Angaben und teilt ihn im Verhältnis der fr-Werte auf.

Im letzten Beispiel gehen zuerst 150px an die erste Spalte. Vom restlichen Platz bekommen die zweite und die dritte je die Hälfte. Ein Anwendungsfall: eine Spalte für ein Logo oder eine Navigation, die immer gleich breit bleibt, während der Rest mitwächst.

repeat() – Schreibarbeit sparen

.wand {
  grid-template-columns: repeat(4, 1fr);        /* = 1fr 1fr 1fr 1fr */
  grid-template-rows: 100px repeat(2, 200px);   /* = 100px 200px 200px */
}

Zeilen

Zeilen definiert ihr genau gleich mit grid-template-rows. Oft lässt man sie aber weg: Die Zeilen werden dann so hoch wie ihr Inhalt. Wollt ihr für automatisch entstehende Zeilen eine feste Höhe, nehmt ihr grid-auto-rows:

.wand {
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: 120px;   /* jede neue Zeile ist 120px hoch */
}

Teil 4: gap – der Abstand zwischen den Bildern

gap kennt ihr schon von Flexbox. Bei Grid legt es den Abstand zwischen Spalten und Zeilen fest – auch getrennt:

.wand {
  gap: 10px;            /* überall gleich */
  /* row-gap: 20px;        nur zwischen Zeilen  */
  /* column-gap: 40px;     nur zwischen Spalten */
}

Teil 5: Linien, nicht Zellen

Jetzt kommt das Wichtigste: Ihr könnt jedes Bild gezielt platzieren. Dafür zählt Grid nicht die Zellen, sondern die Linien dazwischen. Die Nummerierung beginnt bei 1. Ein Raster mit 4 Spalten hat also 5 Spaltenlinien.

Ein Raster mit 4 Spalten und 3 Zeilen – die roten Zahlen sind die Linien

12345
1234
grid-column: 1 / 3
grid-row: 1 / 3

Die Platzierung gebt ihr beim Kind an. grid-column: 1 / 3 heisst: Das Bild beginnt an Spaltenlinie 1 und endet an Spaltenlinie 3. Es belegt also die Spalten 1 und 2.

.bild-gross {
  grid-column: 1 / 3;   /* von Spaltenlinie 1 bis Spaltenlinie 3 */
  grid-row: 1 / 3;      /* von Zeilenlinie 1 bis Zeilenlinie 3 */
}
Denkfalle: grid-column: 1 / 3 heisst nicht „Spalte 1 bis Spalte 3“, sondern „Linie 1 bis Linie 3“ – das sind zwei Spalten. Wenn ein Bild eine Spalte zu schmal ist, liegt es fast immer daran.

Weitere Schreibweisen

.bild {
  grid-column: 2 / span 2;   /* ab Linie 2, zwei Spalten breit */
  grid-column: 1 / -1;       /* von der ersten bis zur letzten Linie */
  grid-row: span 2;          /* zwei Zeilen hoch, Startpunkt automatisch */
}

-1 ist die letzte Linie – praktisch, wenn ein Element immer die ganze Breite einnehmen soll, egal wie viele Spalten das Raster hat.

Oben grid-column: 1 / -1, darunter grid-column: 2 / span 2

1 / -1
2 / span 2

Kurzschreibweise grid-area

Mit grid-area könnt ihr alle vier Linien in einer Zeile angeben. Achtung, die Reihenfolge ist ungewohnt: zuerst die beiden Anfänge, dann die beiden Enden.

.bild-gross {
  /* row-start / column-start / row-end / column-end */
  grid-area: 1 / 1 / 3 / 3;
  /* gleich wie: grid-row: 1 / 3;  grid-column: 1 / 3; */
}

Teil 6: Weissraum

Weil ihr jedes Bild frei platzieren könnt, müsst ihr nicht jedes Feld füllen. Leere Felder bleiben leer – Weissraum wird zum Gestaltungsmittel, wie auf einem Plakat im Swiss Style.

Drei Bilder auf einem 6 × 4-Raster, der Rest bleibt leer

1 / 4 · 1 / 3
4 / 5 · 3 / 5
5 / 7 · 4 / 5
.wand {
  display: grid;
  grid-template-columns: repeat(6, 1fr);
  grid-template-rows: repeat(4, 50px);
}
.titel  { grid-column: 1 / 4; grid-row: 1 / 3; }
.akzent { grid-column: 4 / 5; grid-row: 3 / 5; }
.text   { grid-column: 5 / 7; grid-row: 4 / 5; }

Teil 7: Überlagerungen

Zwei Elemente dürfen dieselben Felder belegen – dann liegen sie übereinander. Das geht mit Flexbox allein nicht. Welches oben liegt, bestimmt die Reihenfolge im HTML, oder ihr steuert es mit z-index.

Das rote Element überlappt das dunkle

1 / 5 · 1 / 4
3 / 7 · 2 / 5
.bild   { grid-column: 1 / 5; grid-row: 1 / 4; }
.akzent { grid-column: 3 / 7; grid-row: 2 / 5; }

/* dunkles Element nach vorne holen */
.bild   { z-index: 1; }

Überlagerungen sind ein typisches Mittel, um aus dem strengen Raster auszubrechen – Text über einem Bild, Bilder, die sich berühren, Elemente, die übereinander hinausragen. Genau das zeigt Jen Simmons in ihren Experimenten.

Teil 8: grid-template-areas – der Hängeplan

Statt mit Liniennummern könnt ihr Bereiche im Raster auch benennen und dann direkt „aufzeichnen“. Jede Zeichenkette ist eine Zeile, jedes Wort ein Feld. Ein Punkt . steht für ein leeres Feld.

.wand {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-template-areas:
    "titel titel titel ."
    "bild  bild  text  text"
    "bild  bild  .     notiz";
}
.titel { grid-area: titel; }
.bild  { grid-area: bild; }
.text  { grid-area: text; }
.notiz { grid-area: notiz; }
titel
bild
text
notiz

Der Code sieht fast so aus wie das Layout. Das macht grid-template-areas besonders anschaulich für Seitenlayouts. Wichtig: Jeder Bereich muss ein Rechteck sein – L-Formen gehen nicht.

Teil 9: Ausrichten in der Zelle

Die Begriffe kennt ihr von Flexbox, bei Grid heissen sie ähnlich. Sie bestimmen, wo ein Element innerhalb seines Feldes sitzt, wenn es kleiner ist als das Feld.

Eigenschaft gesetzt bei Richtung
justify-items Container waagrecht (in der Zeile)
align-items Container senkrecht (in der Spalte)
place-items Container beides in einem: place-items: center;
justify-self / align-self Kind für ein einzelnes Element

Teil 10: Responsive ohne Media Queries

Für Galerien gibt es eine Zeile, die ihr euch merken solltet. Sie sagt: „Mach so viele Spalten, wie hineinpassen – jede mindestens 120px breit, und verteile den Rest gleichmässig.“

.galerie {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(120px, 1fr));
  gap: 10px;
}

  • minmax(120px, 1fr) – eine Spalte ist mindestens 120px und höchstens 1fr breit.
  • auto-fill – so viele Spalten wie möglich. Die Alternative auto-fit verhält sich fast gleich, lässt aber leere Spalten zusammenfallen, wenn es nur wenige Bilder gibt.

Teil 11: Die Petersburger Hängung

Jetzt kommt alles zusammen. Einige Bilder belegen mit span mehr Felder als andere. Normalerweise entstehen dabei Lücken, weil Grid die Bilder streng der Reihe nach einfüllt. Mit grid-auto-flow: dense sucht der Browser für jedes Bild die erste freie Lücke, in die es passt – die Wand wird dicht gehängt.

.wand {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(90px, 1fr));
  grid-auto-rows: 90px;
  grid-auto-flow: dense;   /* Lücken füllen */
  gap: 8px;
}
.quer  { grid-column: span 2; }
.hoch  { grid-row: span 2; }
.gross { grid-column: span 2; grid-row: span 2; }

Teil 12: Grid oder Flexbox?

Beides sind keine Konkurrenten. In den meisten Layouts arbeiten sie zusammen: Grid für die grosse Aufteilung der Seite, Flexbox für die Reihen im Kleinen.

Nehmt Flexbox, wenn … Nehmt Grid, wenn …
Elemente in einer Reihe stehen: Navigation, Button-Leiste, Tags ihr in Zeilen und Spalten gleichzeitig denkt: Seitenlayout, Bildwand
die Grösse der Elemente vom Inhalt abhängen soll das Raster vorgibt, wie gross die Felder sind
Elemente sich den Platz flexibel teilen sollen ihr Weissraum oder Überlagerungen braucht

Ein Grid-Kind kann selbst wieder ein Flex-Container sein – und umgekehrt. Genau wie beim Mobile aus der Flexbox-Einheit.

Überblick

Bei der Wand (Container):

.wand {
  display: grid;

  /* Raster definieren */
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows:    100px 1fr;
  grid-auto-rows:        120px;      /* Höhe automatisch entstehender Zeilen */

  /* Bereiche benennen */
  grid-template-areas:   "titel titel ."
                         "bild  text  text";

  /* Abstände */
  gap:                   10px;       /* row-gap | column-gap */

  /* Ausrichten in den Feldern */
  place-items:           stretch;    /* Standard; auch: center | start | end */

  /* Einfüllen */
  grid-auto-flow:        row;        /* Standard; auch: column | dense */
}

Bei den Bildern (Kinder):

.bild {
  /* nach Linien platzieren */
  grid-column: 1 / 3;        /* Linie 1 bis Linie 3 */
  grid-row:    2 / span 2;   /* ab Linie 2, zwei Zeilen hoch */

  /* Kurzschreibweise: row-start / col-start / row-end / col-end */
  grid-area:   2 / 1 / 4 / 3;

  /* oder nach Namen platzieren */
  grid-area:   bild;

  /* Überlagerung steuern */
  z-index:     1;

  /* Ausrichten im eigenen Feld */
  justify-self: center;
  align-self:   end;
}

Workshop: Die Begrüssung antwortet

Mit CSS kann eure Begrüssung sich bewegen und auf Hover, Klick und Fokus reagieren. Beim Paper Prototyping seid ihr aber auf Ideen gestossen, die CSS nicht kann. Heute kommt JavaScript dazu: Damit merkt sich die Seite, was die Besucherin tut, und antwortet darauf.

Teil 1: Eine Seite, die zurückschaut

Probiert clickclickclick.click aus, ein Browserspiel von Studio Moniker über Online-Profiling. Mit Ton!

  • Was weiss die Seite über euch? Woher?
  • Wie fühlt es sich an, so begrüsst und beobachtet zu werden?
  • Wo liegt die Grenze zwischen Aufmerksamkeit und Überwachung? Denkt an das Spam-«Dear friend».
JavaScript merkt, CSS bewegt. JavaScript beobachtet, was die Besucherin tut: wo sie klickt, wohin sie die Maus bewegt, wie oft, wie lange nichts. Dann schaltet es einen Zustand um, zum Beispiel eine Klasse. Die Bewegung selbst gestaltet ihr weiterhin in CSS, so wie ihr es kennt.

Teil 2: JavaScript einbinden

JavaScript ist neben HTML und CSS die dritte Grundtechnologie des Webs, mit einer eigenen Syntax. Wie CSS lässt es sich direkt ins HTML schreiben oder als eigene Datei einbinden. Wir nehmen eine eigene Datei: script.js neben eurer index.html.

  <!-- ganz am Schluss, direkt vor </body> -->
  <script src="script.js"></script>
</body>
Warum vor </body>? Der Browser liest das HTML von oben nach unten. Steht das Script im <head>, läuft es, bevor die Elemente existieren, und findet nichts.

In script.js testet ihr als Erstes, ob alles verbunden ist:

console.log('Hallo von script.js');

Die Ausgabe seht ihr in den Developer Tools im Tab Console (Rechtsklick → Untersuchen). Die Console ist ab jetzt euer wichtigstes Werkzeug: Fehler erscheinen dort rot.

Teil 3: Elemente finden

JavaScript sieht die Seite als DOM (Document Object Model): eine Abbildung des ganzen HTML-Baums, in der jedes Element gelesen und verändert werden kann. Zugriff darauf gibt die Variable document. Mehr dazu auf w3schools.

Mit querySelector findet ihr ein Element, und zwar mit derselben Schreibweise wie in CSS: Punkt für Klassen, Hash für IDs.

const wort = document.querySelector('.wort');    // erstes Element mit Klasse wort
const hero = document.querySelector('.hero');
const titel = document.querySelector('#titel');  // Element mit der ID titel

console.log(wort); // testen: wurde es gefunden?

// alle passenden Elemente, z. B. alle Buchstaben
const buchstaben = document.querySelectorAll('.wort span');

Findet querySelector nichts, ist das Resultat null. Dann stimmt meistens der Selektor nicht, oder das Script steht an der falschen Stelle.

Teil 4: Auf Ereignisse reagieren

Ein Event ist etwas, das im Browser passiert: ein Klick, eine Mausbewegung, eine Taste. Mit addEventListener sagt ihr einem Element: Wenn das passiert, tu dies.

const wort = document.querySelector('.wort');

wort.addEventListener('click', () => {
  console.log('Jemand hat geklickt!');
});

Das liest sich so: Beim Element wort auf das Ereignis 'click' hören. Wenn es passiert, den Code in den geschweiften Klammern ausführen.

Nützliche Events

Event Wann
click Klick oder Antippen
pointermove Maus oder Finger bewegt sich
pointerenter / pointerleave Maus kommt auf ein Element / verlässt es
keydown Eine Taste wird gedrückt

Wir verwenden pointer… statt mouse…, weil diese Events mit Maus, Finger und Stift funktionieren. Weitere Events findet ihr in der Übersicht auf MDN.

Das Event-Objekt

Bei jedem Event bekommt ihr ein Objekt mit Informationen mit: wo geklickt wurde, auf welches Element, welche Taste. Schaut es euch in der Console an:

document.addEventListener('click', (e) => {
  console.log(e);           // alles
  console.log(e.clientX);   // x-Position im Fenster, in Pixel
  console.log(e.clientY);   // y-Position im Fenster, in Pixel
  console.log(e.target);    // das Element, auf das geklickt wurde
});

Teil 5: Drei Bausteine

Jeder Baustein ist eine Geste im Dialog. Kopiert ihn, passt ihn an, kombiniert ihn mit euren Animationen.

Baustein 1: Antworten – eine Klasse umschalten

Ein Klick schaltet eine Klasse ein oder aus. Das CSS legt fest, was in diesem Zustand passiert. Anders als bei :focus bleibt der Zustand, bis wieder geklickt wird.

const wort = document.querySelector('.wort');

document.addEventListener('click', () => {
  wort.classList.toggle('wach');
});
/* Grundzustand: verschlafen */
.wort span {
  display: inline-block;
  animation: doesen 3s ease-in-out infinite alternate;
}

/* Nach dem Klick: wach */
.wort.wach span {
  animation: aufwachen 0.6s ease-out both;
  animation-delay: calc(var(--i) * 0.08s);
}

classList kann mehr: add('wach') fügt eine Klasse hinzu, remove('wach') entfernt sie, toggle('wach') schaltet hin und her. Mit contains('wach') fragt ihr, ob die Klasse gerade da ist.

Baustein 2: Verdoppeln – die Begrüssung vermehrt sich

Bei jedem Klick entsteht eine Kopie des Worts, genau dort, wo geklickt wurde: aufdringlich wie Spam, ein Echo, eine Menge, die zurückgrüsst.

const hero = document.querySelector('.hero');
const wort = document.querySelector('.wort');

hero.addEventListener('click', (e) => {
  const kopie = wort.cloneNode(true);          // Kopie mit allen Buchstaben
  kopie.classList.add('kopie');
  kopie.setAttribute('aria-hidden', 'true');   // Screenreader lesen nur das Original
  kopie.style.setProperty('--x', e.clientX + 'px');
  kopie.style.setProperty('--y', e.clientY + 'px');
  hero.appendChild(kopie);                     // in die Seite einfügen
});
.hero {
  position: relative;
}

.kopie {
  position: absolute;
  left: var(--x);
  top: var(--y);
  translate: -50% -50%;   /* Mitte der Kopie auf den Klickpunkt */
  font-size: 6vw;
  animation: auftauchen 0.6s ease-out both;
}

Statt an der Klickposition könnt ihr die Kopie auch zufällig platzieren: Math.random() * window.innerWidth gibt eine zufällige Zahl zwischen 0 und der Fensterbreite.

Achtung bei IDs: cloneNode kopiert alles, auch eine ID. Eine ID darf aber nur einmal pro Seite vorkommen. Gebt dem Original darum eine Klasse, keine ID.

Baustein 3: Folgen oder fliehen

JavaScript misst, wo die Maus ist, und gibt die Position als CSS-Variable weiter. CSS verschiebt damit das Wort. Mit einer transition folgt es nicht sofort, sondern mit Charakter: träge, neugierig, scheu.

const wort = document.querySelector('.wort');

document.addEventListener('pointermove', (e) => {
  // Position umrechnen: -0.5 am linken Rand, 0 in der Mitte, 0.5 am rechten Rand
  const x = e.clientX / window.innerWidth - 0.5;
  const y = e.clientY / window.innerHeight - 0.5;
  wort.style.setProperty('--x', x);
  wort.style.setProperty('--y', y);
});
/* Folgen: das Wort bewegt sich in Richtung Maus */
.wort {
  translate: calc(var(--x, 0) * 40vw) calc(var(--y, 0) * 40vh);
  transition: translate 0.8s ease-out;
}

/* Fliehen: einfach das Vorzeichen umdrehen */
.wort.scheu {
  translate: calc(var(--x, 0) * -40vw) calc(var(--y, 0) * -40vh);
}

Die Variablen gelten auch für die Buchstaben im Wort. Bekommt jeder Buchstabe eine eigene Verzögerung, ziehen sie wie eine Schlange hinterher:

.wort span {
  display: inline-block;
  translate: calc(var(--x, 0) * 30vw) calc(var(--y, 0) * 30vh);
  transition: translate 0.6s ease-out;
  transition-delay: calc(var(--i) * 0.06s);
}
Warum translate statt transform? Die eigene Eigenschaft translate kommt sich nicht mit euren Animationen in die Quere, die transform verwenden. So kann ein Buchstabe gleichzeitig hüpfen und der Maus folgen.

Für Neugierige: zählen und warten

JavaScript kann sich etwas merken. Zum Beispiel, wie oft schon geklickt wurde:

let klicks = 0;

document.addEventListener('click', () => {
  klicks++;                         // um eins erhöhen
  if (klicks === 3) {
    wort.classList.add('genervt');  // beim dritten Klick reicht es
  }
});

Oder, ob jemand reagiert. setTimeout führt etwas nach einer bestimmten Zeit aus, hier nach zehn Sekunden ohne Mausbewegung:

let timer = setTimeout(aufgeben, 10000);   // 10000 ms = 10 s

document.addEventListener('pointermove', () => {
  clearTimeout(timer);                     // jemand ist da: Uhr zurücksetzen
  wort.classList.remove('aufgegeben');
  timer = setTimeout(aufgeben, 10000);
});

function aufgeben() {
  wort.classList.add('aufgegeben');
}

Wenn etwas nicht funktioniert

Problem Häufige Ursache
In der Console steht nichts Das Script ist nicht verbunden: Dateiname oder Pfad in src prüfen.
Cannot read properties of null querySelector hat nichts gefunden: Selektor falsch geschrieben (Punkt vergessen?), oder das Script steht im <head>.
… is not a function Tippfehler bei Gross- und Kleinschreibung: addEventlistener statt addEventListener, queryselector statt querySelector.
Die Klasse wird gesetzt, aber nichts bewegt sich In den Developer Tools unter Elements nachschauen, ob die Klasse erscheint. Wenn ja, liegt das Problem im CSS.

  4. Euer Drehbuch und euren Parkplatz anschauen: Welcher Baustein passt zu eurer Szene?

Aufgabe auf 6. November, 18:00: Eine Mini-Begrüssungsszene

Setzt eure Szene um: eine typografische Begrüssung, die den ganzen Bildschirm bespielt und mit der Person rechnet, die die Seite öffnet.

Anforderungen

  • Ein Begrüssungswort in einer Sprache eurer Wahl, gefolgt von etwas mehr: einem zweiten Satz, einer Stimmung, einer Antwort.
  • Mindestens eine eigene @keyframes-Animation mit mehr als zwei Keyframes.
  • Mindestens eine Reaktion auf die Besucherin, mit CSS oder JavaScript.
  • Reduziert die Mittel: Welche Gestaltungselemente braucht es wirklich?
  • Überprüft die Schriftwahl: Welche Schrift passt zur Bewegung?

Möglichkeiten zur Interaktion

Die Besucherin … mit CSS mit JavaScript
nähert sich :hover pointerenter, Baustein 3: Das Wort folgt oder flieht
verweilt transition-delay setTimeout
antwortet, klickt :active, :focus Baustein 1: Der Zustand bleibt. Baustein 2: Die Begrüssung vermehrt sich.
klickt immer wieder – Zähler: Beim dritten Mal passiert etwas anderes
wendet sich ab Transition zurück pointerleave
tut nichts animation-iteration-count, animation-fill-mode setTimeout: Die Begrüssung gibt auf

JavaScript ist kein Muss. Eine starke Szene mit reinem CSS ist besser als eine überladene mit allen Bausteinen. Nehmt nur, was eure Szene erzählt. Und denkt an die Frage von clickclickclick: Wie viel darf eine Begrüssung über ihr Gegenüber wissen?

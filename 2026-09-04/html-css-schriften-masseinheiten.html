Schriften, Masseinheiten & Pfade

Grundaufbau, Selektoren, Farben kennt ihr schon. Heute kommt dazu: wie Text auf dem Web aussieht (Schriftarten, Grössen) und wie man Dateien – z. B. Schriften – überhaupt findet und einbindet.

Teil 1: font-family

Die Eigenschaft font-family gibt eine Liste von Schriftarten an, von der höchsten Priorität bis zur niedrigsten. Der Browser prüft der Reihe nach, ob er die Schrift besitzt – falls nicht, geht er zur nächsten in der Liste.

.serifen {
  font-family: Georgia, serif;
}
.serifenlos {
  font-family: "Gill Sans", sans-serif;
}

Ohne Anführungszeichen: Die Font-Familie ist auf dem Rechner installiert.
Mit Anführungszeichen (oder als generischer Name wie serif, sans-serif): ein genereller Fallback, oder eine Schrift, die extra mitgeliefert wird.

Web Safe Fonts

Websichere Schriftarten sind Schriftarten, die (fast) überall installiert sind. Ganz sicher ist aber nie – es gibt immer die Möglichkeit, dass eine Schrift auf einem Gerät fehlt oder anders installiert ist. Liste: cssfontstack.com

Deshalb gibt man in font-family immer eine Liste von Ausweichschriften an. Findet der Browser die erste nicht, probiert er die nächste, und so weiter. Die Liste endet immer mit einem generischen Familiennamen (serif, sans-serif, monospace ...) als letztem Sicherheitsnetz.

Merke: font-family ist immer eine Liste, nie nur eine einzelne Schrift. Die letzte Angabe sollte immer ein generischer Name sein.

Teil 2: Masseinheiten

CSS-Werte können unterschiedliche Einheiten annehmen. Grob unterscheidet man:

  • fixe Einheiten – immer gleich gross
  • flexible Einheiten – abhängig vom Kontext

Fixe Einheiten

Eine Länge in einer fixen Einheit erscheint immer in genau dieser Grösse.

Abkürzung Grösse
cm Zentimeter
mm Millimeter
in inches (1in = 96px = 2.54cm)
px pixels (1px = 1/96th of 1in)
pt points (1pt = 1/72 of 1in)
pc picas (1pc = 12pt) 
h1 {
  font-size: 32px;
  line-height: 48px;
}

Absolute Längeneinheiten sind für Bildschirme wenig geeignet, da Bildschirmgrössen stark variieren. Sinnvoll sind sie, wenn das Ausgabemedium bekannt ist – z. B. für ein Drucklayout.

px ist relativ zum Anzeigegerät: bei niedriger Pixeldichte entspricht 1px einem Gerätepixel, bei hochauflösenden Bildschirmen (Retina, Drucker) entspricht 1px mehreren Gerätepixeln.

Flexible Einheiten

Flexible Einheiten geben ein Mass relativ zu einer anderen Grösse an. Sie skalieren besser zwischen unterschiedlichen Geräten und Bildschirmen.

Abkürzung Grösse
% relativ zum Parent-Element
em relativ zur Schriftgrösse des eigenen Elements
rem relativ zur Schriftgrösse des Root-Elements (html)
vw 1% der Fensterbreite (Viewport)
vh 1% der Fensterhöhe (Viewport)
Warum rem für Typografie oft die bessere Wahl ist: em bezieht sich auf die Schriftgrösse des eigenen Elements – verschachtelt sich das, können sich Grössen aufsummieren und unerwartet wachsen/schrumpfen. rem bezieht sich immer auf dasselbe Root-Element und bleibt deshalb berechenbarer.

Teil 3: Schriften laden

Wenn du keine der Standard-Schriftarten verwenden willst, kannst du externe Schriften laden – z. B. von Google Fonts oder Adobe Fonts.

Google Fonts generiert dir dafür einen fertigen @import-Befehl:

<head>
<style>
@import url('https://fonts.googleapis.com/css2?family=IBM+Plex+Mono&family=Roboto:wght@100&display=swap');
body {
  font-family: 'Roboto', sans-serif;
}
</style>
</head>

@font-face

Die CSS-Regel @font-face definiert eine eigene Schriftart, die entweder von einem Server oder von einer lokal liegenden Datei geladen wird. Das Attribut src gibt den Pfad zur Schriftdatei an – ohne src ist die Regel ungültig.

@font-face {
  font-family: "Open Sans";
  src: url("/fonts/OpenSans-Regular-webfont.woff2") format("woff2");
}

Einmal definiert, kann die Schrift ganz normal über font-family verwendet werden – so, als wäre sie auf dem Rechner installiert.

Welches Format? WOFF ist ein Format speziell fürs Web – komprimiert, schnellere Ladezeit. WOFF2 ist die neuere, noch stärker komprimierte Version und wird von allen modernen Browsern unterstützt (Check: caniuse.com). Verwendet für neue Projekte immer woff2.

Schriften finden & Lizenzen beachten: Gratis-Schriften z. B. bei velvetyne.fr oder Google Fonts. Schriften sehen, wo sie im Einsatz sind: fontsinuse.com. Achtung: nicht jede Schrift, die du irgendwo findest, darf frei im Web eingebunden werden – Lizenz jeweils prüfen.

Teil 4: Pfade (Adressierung)

Websites sind modular aufgebaut. Anders als in einem Word-File, bei dem alles in ein Dokument eingebettet ist, kann eine Webseite Elemente enthalten, die in anderen Ordnern oder auf anderen Servern liegen – Bilder, Stylesheets, Scripts, Schriften. Damit der Browser weiss, was wo liegt, braucht es Pfade.

<link rel="stylesheet" href="style.css"> <!-- Pfad im href-Attribut -->

<style>
@font-face {
  font-family: "Open Sans";
  src: url("/fonts/OpenSans-Regular-webfont.woff2") format("woff2"); /* Pfad im url()-Attribut */
}
</style>

Absolute Pfade

Ein absoluter Pfad ist die vollständige URL zu einer Datei. Man braucht ihn, wenn die Datei auf einem anderen Server oder einer anderen Domain liegt:

<a href="https://www.w3schools.com/">Visit W3Schools.com!</a>

Relative Pfade

Bei relativen Pfaden ergibt sich der Weg aus dem hierarchischen Bezug zwischen der Datei, in der der Link steht, und der Datei, die eingebunden wird. Man denkt dabei immer von der eigenen Datei aus.

Stellt euch relative Adressierung wie Angaben in einem Gebäude vor: Alles, was im selben Zimmer liegt, könnt ihr direkt ansprechen. Um das Zimmer zu verlassen, müsst ihr erst zur Tür raus – das ist der Schritt, um aus einem Ordner rauszukommen. Wollt ihr in ein anderes Zimmer, nennt ihr dessen Namen – müsst dafür aber schon auf demselben Gang stehen.
Metapher HTML-Pfad-Bedeutung
Du bist im Zimmer aktuelle Datei / aktueller Ordner
Etwas im gleichen Zimmer adressieren <img src="datei.jpg">
Du gehst auf den Gang ../ – eine Ebene höher
Etwas eine Ebene höher adressieren <img src="../datei.jpg">
Du gehst in ein anderes Zimmer ../andererOrdner/
Etwas in einem anderen Zimmer adressieren <img src="../images/datei.jpg"> 
<a href="../seite2.html">Seite 2</a> <!-- liegt ausserhalb des aktuellen Ordners -->

<link rel="stylesheet" href="css/test.css"> <!-- liegt im Ordner "css", gleiche Ebene -->
body {
  background-image: url('img_girl.jpg'); /* liegt im selben Ordner wie die CSS-Datei */
}

Dieselbe Logik gilt für Pfade zu .css- und .js-Dateien, für Links zu anderen Seiten, Hintergrundbilder und – heute relevant – Schriften.

Faustregel: Für externe Ressourcen (andere Webseiten, Schriftserver) nutzt ihr absolute Pfade. Für interne Ressourcen (eure eigene Ordnerstruktur, eigene Unterseiten) nutzt ihr relative Pfade.

Für die Übung heute

Ihr braucht heute vor allem: eine font-family-Liste mit Fallbacks, rem für Schriftgrössen, und – falls ihr eine externe Schrift ladet – den richtigen Pfad im @font-face oder @import. Bei Unsicherheit: erst schauen, ob die Datei relativ zu eurer HTML- oder CSS-Datei liegt, dann den Pfad von dort aus denken.

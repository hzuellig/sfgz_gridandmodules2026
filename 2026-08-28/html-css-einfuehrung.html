HTML & CSS – Kurzeinführung

Diese Einführung deckt nur das ab, was du für die Übung unten brauchst. Für alles Weitere sind MDN und w3schools gute Nachschlagewerke – aber erstmal reicht das hier.

History of the Web, Timetravelling

Am Anfang gab es nur HTML. Und HTML war nie zum Gestalten gedacht – es kommt aus der Wissenschaft, wo man Dokumente austauschen wollte: Überschriften, Absätze, Listen, Links. Es ging darum, Text zu strukturieren, nicht ihn auszusehen zu lassen. Ein <h1> war einfach "das ist wichtig", nicht "das soll gross und fett sein" – wie es dann aussieht, hat der Browser entschieden, nicht die Autorin.
Erst Jahre später kam CSS dazu – mit der ausdrücklichen Idee, Inhalt und Aussehen zu trennen. Vorher hatte man sich beholfen: mit <font>-Tags, mit Tabellen als Layout-Werkzeug, mit einzelnen Pixel-GIFs, um Abstände zu erzeugen. Das Web wollte eigentlich gar nicht gestaltet werden – und wurde dann trotzdem gestaltet, mit den Mitteln, die es nicht dafür hatte.

Teil 1: HTML – Markup

HTML beschreibt die Struktur einer Seite, nicht ihr Aussehen. Man "markiert" Textabschnitte mit Tags, damit der Browser weiß, was es ist: eine Überschrift, ein Absatz, ein Link.

Ein Tag hat meistens eine öffnende und eine schließende Form:

<p>Das ist ein Absatz.</p>

<p> öffnet, </p> schließt. Alles dazwischen ist der Inhalt des Elements.

Die wichtigsten Tags zum Start

Tag Bedeutung Beispiel
<h1> … <h6> Überschriften, h1 = größte/wichtigste <h1>Meine Todo-Liste</h1>
<p> Absatz (Fließtext) <p>Heute erledigen:</p>
<div> Neutraler Container/Block, gruppiert Inhalte <div>...ganzer Block...</div>
<a> Link, braucht ein href-Attribut <a href="https://example.com">Link</a>

Ein <div> hat selbst keine Bedeutung wie "Überschrift" oder "Link" – es ist einfach eine Box, in die du andere Elemente packst, um sie später gemeinsam zu gestalten. Das wird für die Post-its unten wichtig: jedes Post-it ist ein <div>.

Minimalbeispiel

<div>
  <h1>Einkaufen</h1>
  <p>Milch, Brot, Eier</p>
</div>

Teil 2: CSS – Selektoren und Eigenschaften

CSS beschreibt das Aussehen. Eine CSS-Regel besteht aus einem Selektor (auf welches Element wirkt die Regel?) und Eigenschaften in geschweiften Klammern.

Selektoren auf Tags

Der einfachste Selektor ist der Tag-Name selbst – jede Regel gilt dann für alle Elemente dieses Typs auf der Seite:

h1 {
  color: blue;
}

p {
  font-size: 16px;
}

Das war's fürs Erste – Klassen (.name) und IDs (#name) kommen später, wenn du gezielt nur einzelne Elemente ansprechen willst.

Die fünf wichtigsten Eigenschaften

color – Textfarbe

p { color: #333; }

background – Hintergrundfarbe (oder -bild) des Elements

div { background: #fff59d; }

font-size – Schriftgröße

h1 { font-size: 24px; }

border – Rahmen um das Element: Dicke, Stil, Farbe

div { border: 1px solid black; }

margin und padding – der Abstand außen und innen um ein Element:

┌─────────────── margin (Außenabstand zu anderen Elementen) ───────────────┐
│  ┌──────────── border (Rahmen) ─────────────┐                            │
│  │  ┌──── padding (Innenabstand zum Inhalt) ─┐                           │
│  │  │         Inhalt                          │                          │
│  │  └──────────────────────────────────────────┘                        │
│  └────────────────────────────────────────────┘                          │
└─────────────────────────────────────────────────────────────────────────┘
div {
  margin: 16px;
  padding: 12px;
}
Merkregel: padding ist der Abstand innen zwischen Rahmen und Inhalt, margin ist der Abstand außen zu den Nachbar-Elementen.

Übung: Todo-Liste im Post-it-Stil

Baue eine Todo-Liste, bei der jeder Eintrag wie ein Post-it aussieht.

HTML

Jedes Todo ist ein <div> mit einer Überschrift und optional einem Text:

<div>
  <h1>Hausaufgaben</h1>
  <p>Mathe Kapitel 4 durchlesen</p>
</div>

<div>
  <h1>Einkaufen</h1>
  <p>Milch, Brot, Eier</p>
</div>

<div>
  <h1>Sport</h1>
  <p>30 Minuten laufen</p>
</div>

Einzelne HTML Tags nachschauen auf W3School

CSS

Style den div-Tag so, dass er wie ein Klebezettel aussieht: gelber Hintergrund, dezenter Rahmen, Innenabstand, Außenabstand zu den anderen Post-its:

div {
  background: #fff59d;
  border: 1px solid #e6d84b;
  padding: 16px;
  margin: 12px;
  font-size: 16px;
}

h1 {
  font-size: 18px;
}

Experimentiere danach mit:

  • Verschiedene background-Farben pro Post-it (geht erstmal nur, wenn du den Tag änderst – z. B. p anders stylen als div)
  • border dicker/dünner machen, andere Stile (dashed, dotted)
  • Was passiert, wenn margin sehr groß oder padding: 0 ist?
  • Einen <a>-Link auf ein Post-it setzen, z. B. zu einer Quelle oder weiteren Info

Einzelne CSS Eigenschaften nachschauen auf W3School

Bonusfrage zum Nachdenken: Warum sehen mit dem Tag-Selektor div { ... } alle Post-its automatisch gleich aus, auch neue, die du hinzufügst? Was wäre, wenn du nur ein einziges Post-it anders stylen wolltest – reicht der Tag-Selektor dafür noch aus?

Klassen-Selektoren

Der Tag-Selektor div { ... } stylt alle divs gleich. Wenn du nur ein einziges Post-it anders aussehen lassen willst, brauchst du eine Klasse. Gib dem HTML-Element ein class-Attribut:

<div class="wichtig">Nicht vergessen!</div>

Und im CSS sprichst du diese Klasse mit einem Punkt . vor dem Namen an:

.wichtig {
  background: #ff8a65;
  border: 2px dashed #d84315;
}

Wichtig: Die Klasse ergänzt den Tag-Selektor, sie ersetzt ihn nicht. Das Post-it bekommt zuerst alles von div { ... } (Innenabstand, Außenabstand, Schriftgröße) – und danach überschreibt .wichtig { ... } nur die Eigenschaften, die dort auch definiert sind.

Experimentiere danach mit:

  • Gib zwei oder drei Post-its die Klasse wichtig und schau, ob sie wirklich alle die Klasse teilen
  • Erfinde eine zweite Klasse, z. B. erledigt, mit einem anderen Look (z. B. opacity: 0.5)
  • Kombiniere zwei Klassen an einem Element: class="wichtig erledigt"
Bonusfrage zum Nachdenken: Was, wenn du zwei Post-its die gleiche Klasse wichtig gibst, aber eines davon soll trotzdem eine ganz eigene, einmalige Formatierung bekommen, die kein anderes Element je haben soll? Reicht die Klasse dafür noch – oder braucht es etwas anderes?

ID-Selektoren

Für ein Element, das es auf der ganzen Seite nur ein einziges Mal gibt, benutzt man statt class ein id-Attribut:

<div id="chef-notiz">Von der Chefin persönlich</div>

Im CSS wird die ID mit einer Raute # angesprochen:

#chef-notiz {
  background: #333;
  color: white;
  transform: rotate(-3deg);
}
Merke: Eine Klasse (.name) kannst du beliebig oft vergeben, eine ID (#name) nur genau einmal pro Seite. Als Faustregel: Klassen für "diese Art von Element", ID für "genau dieses eine Element".

Cursor mit Superkraft (eigenes Icon)

CSS kann den Mauszeiger durch ein eigenes Bild ersetzen – mit cursor: url(...). Damit wird dein Zeiger selbst zur Figur, die über die Seite fährt:

body {
  cursor: url("assets/ghost.jpg") 8 8, auto;
}

Du kannst ein Icon als Cursor benutzen, z. B. von flaticon.com. Lade dort ein Icon als .svg oder .png herunter und leg es neben deine index.html, z. B. in einen Ordner icons/geist.png: 

body {
  cursor: url("icons/geist.png") 8 8, auto;
}

Die zwei Zahlen (8 8) sind wieder der Hotspot – der Punkt im Bild, der als Klickposition zählt. Bei einem 32×32px-Icon ist das oft ungefähr die Mitte.

Wichtig zur Grösse: Browser ignorieren Cursor-Bilder, die zu gross sind (meist über 128×128px, teils schon ab 32×32px). Ist dein Icon zu gross, öffne es kurz in einem Bildbearbeitungs-Tool und verkleinere es, bevor du es einbindest.
Zur Lizenz: Icons auf Flaticon sind meist unter Creative-Commons-Lizenz mit Namensnennung – beim Download steht jeweils dabei, wie die Attribution aussehen muss (z. B. "Ghost by XY from Flaticon"). Baut das am Ende irgendwo auf eurer Seite ein, z. B. im Footer.

Workshop: Begrüssungen animieren

Mit Transitions habt ihr Begrüssungen von einem Zustand in einen anderen gebracht. Heute gehen wir einen Schritt weiter: Mit Animationen bewegt sich eine Begrüssung durch beliebig viele Zustände, von selbst, wiederholt, getimt. Heute arbeitet jede und jeder für sich.

Teil 1: Was sind CSS-Animationen?

CSS-Animationen können mehr als Transitions. Eine Transition kennt nur Zustand A und Zustand B. Bei einer Animation könnt ihr beliebig viele Zustände dazwischen festlegen, sogenannte Keyframes.

Transition Animation
Zustände Zwei: vorher und nachher Beliebig viele Keyframes
Auslöser Eine Zustandsänderung, z. B. :hover Läuft von selbst, sobald die Seite lädt
Wiederholung Nein Beliebig oft, auch endlos
Eine Transition ist ein Schnitt mit Überblendung: Anfangsbild, Endbild, dazwischen rechnet der Browser. Eine Animation ist ein Daumenkino: Ihr zeichnet die wichtigen Seiten selbst, und der Browser füllt die Lücken dazwischen.

Teil 2: Die Syntax

Eine Animation besteht aus zwei Teilen: Zuerst wird sie mit @keyframes entworfen, dann wird sie einem Element zugewiesen.

/* 1. Animation entwerfen */
@keyframes hereinschieben {
  from {
    transform: translateX(0%);
  }
  to {
    transform: translateX(100%);
  }
}

/* 2. Animation zuweisen */
.wort {
  animation-name: hereinschieben;
  animation-duration: 3s;
}
  • Den Namen nach @keyframes wählt ihr frei. Mit diesem Namen wird die Animation zugewiesen.
  • from ist der Keyframe bei 0 %, to der bei 100 %.
  • In jedem Keyframe stehen die CSS-Eigenschaften, die sich verändern sollen.
  • Anders als bei transition müsst ihr nicht angeben, welche Eigenschaften animiert werden. Alles, was in den Keyframes steht, wird animiert.

Mehr als zwei Zustände: Prozente

Statt from und to könnt ihr Prozente angeben. Jeder Keyframe kann mehrere Eigenschaften gleichzeitig verändern:

@keyframes winken {
  0% {
    transform: rotate(0deg);
    color: black;
  }
  25% {
    transform: rotate(-15deg);
  }
  50% {
    transform: rotate(15deg);
    color: red;
  }
  75% {
    transform: rotate(-10deg);
  }
  100% {
    transform: rotate(0deg);
    color: black;
  }
}

/* Keyframes mit gleichem Zustand lassen sich zusammenfassen */
@keyframes pulsieren {
  0%, 100% { opacity: 1; }
  50%      { opacity: 0.2; }
}

Teil 3: Die Animation steuern

Mit weiteren Eigenschaften steuert ihr, wie eine Animation abläuft:

Eigenschaft Was sie macht Beispiel
animation-duration Dauer eines Durchgangs 3s, 800ms
animation-delay Wartezeit vor dem Start 1s
animation-iteration-count Wie oft die Animation abgespielt wird, Standard ist 1 3, infinite (endlos)
animation-direction Richtung pro Durchgang siehe unten
animation-timing-function Beschleunigung, wie transition-timing-function ease-in-out, linear, steps(5)
animation-fill-mode Was vor dem Start und nach dem Ende gilt siehe unten
animation-play-state Läuft oder ist angehalten running, paused

animation-direction

  • normal: Jeder Durchgang läuft vorwärts und beginnt wieder am Anfang. Das ist der Standard.
  • reverse: Jeder Durchgang läuft rückwärts, vom Endzustand zum Anfang. Auch die Timing-Funktion wird umgekehrt.
  • alternate: Die Richtung wechselt bei jedem Durchgang: vorwärts, rückwärts, vorwärts … Ideal für Bewegungen, die hin und her pendeln.
  • alternate-reverse: wie alternate, aber der erste Durchgang läuft rückwärts.

animation-fill-mode

Ohne weitere Angabe springt ein Element nach der Animation zurück in seinen ursprünglichen Zustand. Das ist oft nicht gewünscht.

  • forwards: Das Element behält nach dem Ende den Zustand des letzten Keyframes. Oft genau das, was man will.
  • backwards: Während der Wartezeit (animation-delay) gilt schon der erste Keyframe. So blitzt das Element vor dem Start nicht kurz im falschen Zustand auf.
  • both: beides zusammen. Für Animationen mit Verzögerung meistens die beste Wahl.

animation-play-state

Mit paused wird eine Animation angehalten. Läuft sie mit running weiter, setzt sie dort fort, wo sie unterbrochen wurde, und beginnt nicht von vorne. Zusammen mit :hover lässt sich so eine Animation anhalten:

.wort:hover {
  animation-play-state: paused;
}

Kurzform: animation

Die Eigenschaft animation fasst alle Angaben zusammen:

/* duration | timing-function | delay | iteration-count | direction | fill-mode | play-state | name */
animation: 3s ease-in 1s 2 reverse both paused hereinschieben;

/* meistens reicht viel weniger */
animation: hereinschieben 3s ease-in-out both;
Zwei Zeitangaben? Die Reihenfolge der Werte ist ziemlich frei. Bei den Zeiten aber gilt: Die erste ist immer die Dauer, die zweite die Verzögerung.

Teil 4: Buchstabe für Buchstabe

Typografische Animationen werden spannend, wenn sich nicht das ganze Wort bewegt, sondern jeder Buchstabe einzeln, leicht versetzt.

1. Jeden Buchstaben in ein span packen

<h1 class="wort" aria-label="Hallo">
  <span aria-hidden="true" style="--i: 0">H</span>
  <span aria-hidden="true" style="--i: 1">a</span>
  <span aria-hidden="true" style="--i: 2">l</span>
  <span aria-hidden="true" style="--i: 3">l</span>
  <span aria-hidden="true" style="--i: 4">o</span>
</h1>

Mit aria-label liest ein Screenreader das ganze Wort «Hallo» vor statt «H, a, l, l, o». Die einzelnen Buchstaben sind darum mit aria-hidden ausgeblendet. Die Variable --i ist die Nummer des Buchstabens.

2. Animation mit gestaffelter Verzögerung

.wort span {
  display: inline-block; /* wichtig! */
  animation: huepfen 1.2s ease-in-out infinite alternate;
  animation-delay: calc(var(--i) * 0.12s);
}

@keyframes huepfen {
  0% {
    transform: translateY(0) rotate(0deg);
  }
  60% {
    transform: translateY(-24px) rotate(-6deg);
  }
  100% {
    transform: translateY(0) rotate(4deg);
  }
}
Warum display: inline-block? Ein span ist standardmässig ein Inline-Element, und auf Inline-Elemente wirkt transform nicht. Ohne diese Zeile bewegt sich nichts.

calc(var(--i) * 0.12s) rechnet für jeden Buchstaben die eigene Verzögerung aus: 0s, 0.12s, 0.24s … So entsteht die Welle, ohne dass ihr für jeden Buchstaben eine eigene Regel schreiben müsst.

Rücksicht auf weniger Bewegung

Bei Animationen, die von selbst und endlos laufen, ist das noch wichtiger als bei Transitions. Wer im Betriebssystem «Bewegung reduzieren» eingestellt hat, sollte eine ruhige Version sehen:

@media (prefers-reduced-motion: reduce) {
  .wort span {
    animation: none;
  }
}

Zum Nachlesen: CSS-Animationen verwenden (MDN)

Aufgabe auf 6. November, 18:00: Eine Begrüssung, die den Screen erobert

Entwickelt allein eine typografische Animation mit einem einzigen Begrüssungswort. Die Animation bespielt wie ein Hero den ganzen Bildschirm. Es ist das Erste, was man sieht, wenn man die Seite öffnet.

Anforderungen

  • Ein Begrüssungswort, in einer Sprache eurer Wahl. Es darf auch eines aus unserer Sammlung sein.
  • Die Animation füllt den ganzen Viewport, ohne Scrollbalken.
  • Mindestens eine eigene @keyframes-Animation mit mehr als zwei Keyframes.
  • Die Bewegung erzählt etwas über die Begrüssung: Ist sie förmlich, herzlich, laut, scheu, aufdringlich wie Spam?
  • Reduziert die Mittel: welche Gestaltungselemente braucht es wirklich?
  • Überprüft die Schriftwahl: welche Schrift passt zur Bewegung?

Inspirationen

  • Plakatsammlung Museum für Gestaltung
  • AWWWards Kinetic Typografie
  • Studio Dumbar
  • Kinetic Type
  • ShyMagazine

Ideen zum Weiterdenken

  • Das Wort ist grösser als der Screen und wandert langsam durchs Bild.
  • Die Buchstaben kommen aus verschiedenen Richtungen und finden sich.
  • Mehrere Schichten wie in der Überlagerungs-Übung, die sich gegeneinander verschieben.
  • Die Begrüssung wiederholt sich aufdringlich, wie ein Spam-«Dear».
  • steps() statt weicher Bewegung, wie eine Schreibmaschine.
  • Kombination mit einem Bild

Bringt eure Animation nächstes Mal mit. Wir schauen sie gemeinsam an, auf dem grossen Screen.
